# The mono-green test deck

The owner's Basic Mono Green 60-card deck (`Test Deck/To export/
Basic_Mono_Green_60_Card_Deck.txt`), without its printings, so CI can
build it with generated pictures. Spec 0095's real-game speed test plays
it on both seats to a table of 28+ permanents and times five moments.

```text
Green Test Deck.txt   24 Forest
                      4 Llanowar Elves, 4 Grizzly Bears, 4 Centaur Courser
                      4 Steel Leaf Champion, 4 Thornhide Wolves
                      4 Colossal Dreadmaw
                      4 Giant Growth, 4 Titanic Growth, 4 Rabid Bite
```

Used by `frontend/e2e/match-speed.spec.ts`.
