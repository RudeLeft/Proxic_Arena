# The swarm test deck

A legal 60-card Open Format deck that floods the board with identical
1/1 Goblin tokens, for big combats (specs 0036 and 0037): stacks of
identical tokens, blockers riding on their attackers, and blocking a
stack with a stack ("block many at once").

```text
Swarm Test Deck.txt   36 Mountain
                      4 Dragon Fodder, 4 Krenko's Command (two Goblins)
                      4 Hordeling Outburst (three), 4 Goblin Rally (four)
                      4 Beetleback Chief (two), 4 Goblin Instigator (one)
```

Every token is the same 1/1 red Goblin, and BOTH players play the same
deck. Used by `frontend/e2e/match-big-combat.spec.ts`.
